# Third-Party Assets

The playable project currently uses the assets already committed under `Assets/Art` and `Assets/Multiplayer`.

The following packages are available locally for evaluation but are intentionally excluded from this repository until a final integration and redistribution review is completed:

| Package | Local path | Current status |
|---|---|---|
| Pose Blender Lite | `Assets/BSS/PoseBlenderLite` | Evaluated; character, AK, pose overlays, and IK are usable, but the imported package does not contain a complete locomotion set. |
| Sights Aligner | `Assets/Kinemation/SightsAligner` | Evaluated dependency; not integrated. |
| Toon Shooter Game Kit | `Assets/Art/Toon Shooter Game Kit - Dec 2022` | Candidate art and character package; not integrated. |
| Universal Base Characters Standard | `Assets/Art/Universal Base Characters[Standard]` | Candidate character package; not integrated. |

Do not assume that possession of a package grants permission to redistribute its source files. Keep the original license/download record for every package and import licensed packages locally when working on the project.
